hx help
hx doctor

AI operation

Plans before mutation.

Mutating commands expose explicit plans, side effects, and evidence commands. AI operators can inspect JSON before applying changes. 

hx status --json
hx add aeson --target=exe:server --plan --json
hx linker use auto --plan --json
hx doctor --json

Boundary

Pre-beta means narrow claims.

  • Implemented: init, status, add, linker, run, test, doctor, ci.
  • Claimed: Cabal-first lifecycle command plane.
  • Not claimed: Cabal replacement, Hackage replacement, Stack-first support, production toolchain management.
