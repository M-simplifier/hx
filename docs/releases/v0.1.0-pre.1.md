# v0.1.0-pre.1

Draft date: 2026-05-08

## Summary

This is the first public pre-beta candidate for `hx` as a Cabal-first Haskell
lifecycle command plane.

## Included

- `hx init`
- `hx status`
- `hx add`
- `hx doctor`
- `hx build`
- `hx run`
- `hx test`
- `hx ci`
- machine-readable plan/evidence output for the supported lifecycle commands

## Verification

Release verification should include:

```bash
cabal build all
cabal test hx-smoke
scripts/public-ci.sh
scripts/release-preflight.sh v0.1.0-pre.1
```

## Claim Boundary

This release claims a repo-first public pre-beta for Cabal projects. It does not
claim to replace Cabal, Hackage, Stack, or system toolchain managers.

## Install

```bash
cabal install exe:hx --installdir="$HOME/.local/bin" --overwrite-policy=always
```
