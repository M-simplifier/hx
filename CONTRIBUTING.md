# Contributing

`hx` is currently public pre-beta software. Feedback is welcome, but support and
maintenance response are not guaranteed.

## Issues

Please use GitHub Issues for:

- reproducible bugs
- documentation corrections
- questions about the current public claim boundary
- small concrete requests

Bug reports should include:

- host OS and whether WSL is involved
- `ghc --numeric-version`
- `cabal --numeric-version`
- `hx version`
- `hx doctor` output from the affected project
- the exact command that failed

## Pull Requests

Outside pull requests are not the normal contribution path yet. Opening an
issue first is preferred.

Maintainers may implement accepted issues in this repository, but no schedule or
release is guaranteed.

## Security And Production Use

This project is not ready for production use. Do not rely on it for
security-sensitive or availability-sensitive systems.
